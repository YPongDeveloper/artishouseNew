# The Heritage House Bangkok · เรือนศิลป์ริมน้ำ (Demo Showcase)

เว็บไซต์ต้นแบบสำหรับนำเสนอผลงาน (Interactive Demo Showcase) เพื่อประชาสัมพันธ์พื้นที่ศิลปวัฒนธรรมและการท่องเที่ยวเชิงสร้างสรรค์ **The Heritage House (เรือนศิลป์ริมน้ำ)** โดดเด่นด้วยสถาปัตยกรรมเรือนไม้ไทยโบราณริมสายน้ำประวัติศาสตร์

## ฟีเจอร์เด่น (Features)
- **ระบบแผนที่นำทางจำลอง (Leaflet Map Integration):** ระบบแผนที่จำลองพร้อมหมุดปัก Custom Pin และระบบป้องกันหมุดคลาดเคลื่อนขณะซูม
- **รองรับการแสดงผลหน้าบ้านความเร็วสูง:** ปรับแต่งภาพ (WebP) และทำ Lazy Loading เพื่อรองรับเน็ตมือถือความเร็วต่ำ (ทดสอบความเร็วแล้วบนโปรไฟล์ 128 Kbps)
- **ความปลอดภัยเชิงลึก (Security Hardening):** บล็อกการคลิกขวา, ปิดการกด F12/Inspect Tool, ใส่ CSP Header และระบบป้องกันการซูมหน้าจอผิดสัดส่วน (Zoom Guard)
- **สไตล์สีทองคลาสสิกไทยโบราณ (Thai Golden Art Theme):** ใช้ฟอนต์ไทยประยุกต์โบราณและคู่สีทอง-แดงมารูนหรูหรา

## ผลการทดสอบประสิทธิภาพ (Performance Simulation - 128 Kbps)
จำลองการทดสอบด้วย Lighthouse ผ่านเครือข่ายความเร็วต่ำ **128 Kbps (Slow 2G)** และ Latency 300ms เพื่อรับประกันการเข้าถึงที่ราบรื่นสำหรับทุกคน:

| ดัชนีวัดผล (Metrics) | คะแนน / เวลาที่ใช้ | ความหมายเชิงลึกในการใช้งานจริง |
| :--- | :--- | :--- |
| **Performance Score** | 🌟 69 / 100 | ถือว่าสูงมากสำหรับเน็ต 128 Kbps (เนื่องจากเว็บทั่วไปจะหล่นไปอยู่ในช่วงต่ำกว่า 20 คะแนน) |
| **First Contentful Paint (FCP)** | 🟢 3.0 วินาที | หน้าเว็บเริ่มแสดงผลข้อความแรกและโครงร่างเว็บให้เห็นภายใน 3 วินาทีแรก แม้เน็ตจะช้ามาก |
| **Largest Contentful Paint (LCP)** | 🟡 9.3 วินาที | ภาพองค์ประกอบหลักที่ใหญ่ที่สุดถูกโหลดครบถ้วนที่ 9.3 วินาที (จากขนาดไฟล์เว็บรวมที่ประมาณ 1.5MB) |
| **Cumulative Layout Shift (CLS)** | 🟢 0 (สมบูรณ์แบบ) | หน้าเว็บไม่มีอาการขยับหรือกระตุกเลย ขณะรูปภาพต่าง ๆ ทยอยโหลดเข้ามา (เพราะจองความกว้าง/สูงไว้แล้ว) |
| **Total Blocking Time (TBT)** | 🟢 100 มิลลิวินาที | หน้าเว็บโหลดมาแล้วไม่ค้างเบราว์เซอร์ลื่นไหล สามารถเลื่อนอ่านและมีปฏิสัมพันธ์ได้ทันที |
